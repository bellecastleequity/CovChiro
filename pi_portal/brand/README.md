# InjuryCase brand kit

Every file here is generated by `src/build.py` (SVGs, with all text converted
to outlines) and `src/render.mjs` (a PNG for every SVG), so the logo is exact
and reproducible. Change the mark in `src/mark.py`, then run:

    python3 src/build.py && node src/render.mjs "$(pwd)"

Each item has an SVG here and a PNG of the same name in `png/` (transparent
background unless the item is a board with its own).

| File | Use |
|---|---|
| `injurycase-logo-horizontal` | Primary logo on white/light backgrounds |
| `injurycase-logo-horizontal-dark` | Primary logo on navy/dark backgrounds |
| `injurycase-logo-stacked` / `-stacked-dark` | Square spaces: social profiles, signage |
| `injurycase-mark` | App icon (indigo tile) |
| `injurycase-mark-navy` | App icon on a navy tile |
| `injurycase-favicon-32` / `-favicon-16` | Browser icons (16px uses the simplified "i" + arrow) |
| `injurycase-mark-small` | The simplified mark, for anything 16px or smaller |
| `injurycase-logo-mono-black` / `-mark-mono-black` | One color: fax, print, embossing |
| `injurycase-logo-mono-white` / `-mark-mono-white` | One color on dark backgrounds |
| `injurycase-wordmark` / `-wordmark-dark` | Text only |
| `injurycase-logo-tagline-manage(-dark)` | With "Manage Cases / Move Patients Forward" |
| `injurycase-logo-tagline-settlement(-dark)` | With "From First Visit / to Final Settlement" |
| `injurycase-palette` | Color palette and tints |
| `injurycase-typography` | Typeface specimen |
| `injurycase-clear-space` | Clear-space rule |
| `injurycase-icon-sizes` | The icon at 128 / 64 / 32 / 16 px |
| `injurycase-brand-sheet` | Everything on one board |
| `png/injurycase-mark-{48..512}.png`, `favicon.ico`, `apple-touch-icon.png`, `icon-512-maskable.png` | App and site icons |

- **Colors:** Indigo `#2B3FD6` (primary), Mint `#5EEAD4` (the rising arrow,
  progress, done) and Navy `#0F1733` (text, dark backgrounds). Tints: indigo
  `#959FEA` / `#CAD0F5`, mint `#9EF2E5` / `#DFFAF6`.
- **Website and app:** indigo buttons and links (white text), mint as a fill
  with navy text for done/progress states (mint is too light for text on
  white), navy text and sidebar, on `#F4F6FB`. Supporting colors keep their
  meaning everywhere: red = urgent, amber = needs attention, blue =
  information, violet = legal stages, teal = settled.
- **Type:** Inter — Medium for "Injury", Bold for "Case" (SIL Open Font
  License). The wordmark in these files is already converted to outlines.
- **On dark backgrounds** use the `-dark` lockups: the indigo icon, white
  "Injury", indigo "Case".
- **Clear space:** keep space equal to the height of the "i" (dot to
  baseline) free on all sides. Don't recolor, stretch, rotate, add effects,
  or rebuild the wordmark in another font.
