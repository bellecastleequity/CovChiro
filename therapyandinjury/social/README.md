# Social media launch kit

| Path | What it is |
|---|---|
| `account-setup.md` | Instagram and Facebook brand account setup: bio, category, link, profile picture, posting rules |
| `gbp/<city>.md` | Google Business Profile setup sheet per branch (generated by `gbp/generate.mjs` from `branches.json`) |
| `posts/01–12.html` | 12 launch posts, 1080×1080, editable HTML |
| `stories/01–03.html` | 3 story templates, 1080×1920 |
| `captions.md` | Caption and hashtags for every post and story |
| `calendar.csv` | 4-week posting calendar (opens in Excel or Google Sheets) |
| `export.mjs` | Renders every template to PNG for each city |

## Editing a template
Open any `.html` file in Chrome and edit the text in a code editor. Styles shared by all templates are in `assets/post.css`.

The city is swappable from the URL:
- `posts/09-now-open.html?city=Orlando` shows "Orlando Therapy & Injury"
- `posts/01-brand-intro.html?city=` shows the brand-level "Therapy & Injury"
- `&address=…&hours=…&phone=…` fill the address, hours, and phone fields

## Exporting PNGs
```bash
npm install                      # once (installs Playwright)
npx playwright install chromium  # once per computer
npm run social:export            # every city -> social/export/<city>/
npm run social:export -- ocala   # one city ("brand" for the brand account)
```
Each export pulls the city, address, and hours from `src/data/branches.json`. "Now open" templates are exported only for open branches.

## Compliance built in
- Every template footer says "Chiropractic · Michael L. McPherson, D.C."
- Health tips carry "Educational only, not medical advice."
- No offers, testimonials, "best"/"#1" claims, or guarantees.
- All accident content is general education. Never target or reply to a specific crash or person.
